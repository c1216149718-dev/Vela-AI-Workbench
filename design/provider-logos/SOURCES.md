# Vela provider logo sources

Bundled marks are fetched from provider-owned properties and displayed without recoloring or geometric changes.

- DeepSeek: existing official product mark from `api-docs.deepseek.com`.
- APIKEY.FUN: existing product mark supplied for the verified connector.
- SiliconFlow: `https://www.siliconflow.cn/favicon.ico` (PNG payload).
- Moonshot/Kimi: `https://platform.moonshot.cn/favicon.ico`.
- 智谱 GLM: `https://static.bigmodel.cn/wd-paas-front/static/images/favicon.png`.
- 阿里百炼: `https://img.alicdn.com/tfs/TB1_ZXuNcfpK1RjSZFOXXa6nFXa-32-32.ico`.
- 火山方舟: `https://portal.volccdn.com/obj/volcfe/misc/favicon.png`.
- 腾讯 TokenHub: `https://cloud.tencent.com/favicon.ico`.
- 百度千帆: `https://bce.bdstatic.com/img/newfavicon.ico`.
- OpenAI: official OpenAI GitHub organization avatar `https://avatars.githubusercontent.com/u/14957082`.

The ICO resources were rasterized to PNG without recoloring. All marks render inside the same 48dp container with a 30dp optical frame.
